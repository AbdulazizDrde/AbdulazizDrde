# Abdulaziz Drde Personal Brand Website

Source for the personal technology brand of **Abdulaziz Drde | عبدالعزيز دردي**.

## Positioning

**Digital Transformation & Technology Operations**

> Building digital operating systems at the intersection of technology, operations, data, AI, and business.

## Brand model

**Operator × Builder × Researcher × Writer**

## Architecture

- Next.js static export
- Bilingual Arabic / English
- Work / Writing / Field Notes / Lab / Frameworks / About
- Evidence labels: BUILT / TESTED / MEASURED / OBSERVED / RESEARCH / HYPOTHESIS
- Schema.org ProfilePage / Person metadata
- Responsive editorial technology design

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The project uses `output: 'export'` and can be deployed to Vercel or any static host.
